A horror game made in a 5-day Game-Jam.
Originally, the game did not have a level editor.
The level editor was added after the game jam had already finished.

The code seen in the base game blueprints remains the same as it was when the game jam finished (apart from a few comments)
The Level Editor uses new blueprints for the main mechanics of the game.
These blueprints are copies of the original ones but have improved and more optimised code. (Improved readability and efficiency)
